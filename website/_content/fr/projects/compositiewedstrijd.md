**2011 · Projet historique**

Une annonce externe de 2011 décrit un concours de composition IVME pour les jeunes de 12 à 16 ans. Les catégories concernaient les cuivres et les ensembles de percussion. Le dossier historique disponible ne contient pas les résultats.

Cette description repose sur une reconstitution historique à partir de sources externes. Il ne s’agit pas d’un appel ou d’une activité en cours.
